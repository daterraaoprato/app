ALIMENTAÇÃO SAUDÁVEL NA INFÂNCIA — COMO ALIMENTAR O SITE
==========================================================

OBJETIVO
-------
O site NÃO possui tela de cadastro para o usuário final.
Categorias, alimentos, receitas e conteúdos educativos são preparados ANTES da apresentação pelas alunas.

ONDE ALTERAR O CONTEÚDO
-----------------------
Abra a pasta "dados":

  dados/categorias.js  -> grupos de alimentos
  dados/alimentos.js   -> alimentos, descrição e benefícios
  dados/receitas.js    -> receitas, ingredientes, preparo e substituições
  dados/conteudos.js   -> textos educativos

Normalmente não é necessário alterar index.html, css/style.css ou js/app.js.

IMAGENS
-------
Coloque as imagens nas pastas:

  imagens/alimentos/
  imagens/receitas/

Depois informe o caminho no item correspondente, por exemplo:

  imagem: "imagens/alimentos/maracuja.jpg"

Se o campo imagem ficar vazio, o site mostra o ícone/emoji definido no item.

COMO RELACIONAR OS DADOS
------------------------
1) Cada categoria possui um id único:
   id: "frutas"

2) Um alimento aponta para a categoria:
   categoriaId: "frutas"

3) Uma receita pode se relacionar a vários alimentos:
   alimentos: ["maracuja", "aveia"]

IMPORTANTE: os ids devem ser exatamente iguais nos arquivos relacionados.

FAVORITOS
---------
Favoritos são a única informação criada pelo visitante.
Eles ficam no localStorage do navegador e não alteram os arquivos do projeto.

COMO ABRIR
----------
Pode abrir index.html diretamente no navegador, pois os dados são arquivos JavaScript locais.
Não é necessário banco de dados nem servidor web para a apresentação.

DICA PARA USAR IA
-----------------
Use o arquivo MODELOS_PARA_IA.txt. Ele possui modelos prontos que podem ser enviados para uma IA junto com o conteúdo da receita/alimento.
